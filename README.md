# GTU – المنصة الوطنية لخريجي التقنيات الحضرية في الجزائر

منصة رقمية وطنية ومهنية واجتماعية وإدارية موحدة تجمع خريجي تخصص **التقنيات الحضرية** في الجمهورية الجزائرية الديمقراطية الشعبية عبر **58 ولاية** و**1541 بلدية**.

## المزايا والوحدات الرئيسية

1. **التسجيل والعضوية الوطنية**:
   - استمارة تسجيل شاملة (البيانات الشخصية، الأكاديمية، الجغرافية، والحساب).
   - استصدار رقم عضوية وطني فريد (`GTU-YYYY-XXXXXX`).
   - تشفير كلمات المرور بخوارزمية `scrypt` مع ملح عشوائي (Salt) + دعم تسجيل الدخول عبر Google (Firebase Auth).
   - استعادة كلمة المرور، إدارة الجلسات النشطة، وحذف الحساب.
2. **النظام الجغرافي الرسمي للجزائر**:
   - قاعدة بيانات متكاملة تضم **58 ولاية** و**1541 بلدية** رسمية في `data/algeria-wilayas-communes.json`.
   - ربط صارم بين الولاية وبلدياتها مع منع التكرار، وخريطة وطنية تفاعلية قابلة للتكبير والبحث.
3. **لوحة القيادة الوطنية والدليل**:
   - مؤشرات حقيقية مباشرة من PostgreSQL (الخريجين، الولايات الممثلة، البلديات، الأعضاء النشطين، الاقتراحات، الفعاليات، الرسائل).
   - دليل الخريجين المحمي (متاح للمسجلين فقط) مع إخفاء رقم الهاتف وتاريخ الميلاد افتراضياً.
4. **فضاء التواصل الفوري (WebSockets)**:
   - الشات الوطني العام، 58 مجموعة ولائية، المحادثات الخاصة (مع الحظر والإبلاغ)، وقناة الإعلانات الرسمية، ودعم المرفقات.
5. **المبادرات، الاقتراحات، الفعاليات، والتقارير**:
   - نظام اقتراحات بـ 6 حالات وسجل تطور، تنظيم الفعاليات وتأكيد الحضور، إعلانات وطنية وولائية، مركز إشعارات، وتصدير التقارير (`PDF` للطباعة RTL، `Excel .xlsx`، `CSV`، و`JSON`).
6. **PWA والعمل دون إنترنت**:
   - تثبيت التطبيق عبر `vite-plugin-pwa`، حفظ المسودات، وقائمة انتظار للمراسلات والاقتراحات تُزامن تلقائياً عند عودة الاتصال.

## التشغيل المحلي

```bash
npm install
npm run dev
```

تعمل المنصة (Express + WebSockets + Vite) على المنفذ `3000`.
